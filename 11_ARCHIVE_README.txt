TO RECONSTRUCT THE FULL ARCHIVE
1. Download all 11_Full_Research_Archive.zip.001 through .013 files.
2. Download 11_Reassemble_Archive.py into the same folder.
3. In that folder run: python 11_Reassemble_Archive.py
   Python 3 is the only requirement; no additional packages are needed.
4. The script verifies every part, joins them, and verifies the original ZIP.
5. Extract 11_Full_Research_Archive.zip and follow its README.

Do not try to unzip individual parts. Allow 0.80 GB for the assembled
ZIP in addition to the downloaded parts and space for extracted research.
